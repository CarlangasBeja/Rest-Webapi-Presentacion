01 · FUNDAMENTOS

Conceptos fundamentales

Antes de utilizar REST debemos comprender los conceptos principales.

API

API

Una API o Interfaz de Programación de Aplicaciones establece reglas para que diferentes programas puedan comunicarse.

Interfaz
WEB

Web API

Es una API accesible mediante tecnologías web. Generalmente utiliza HTTP para enviar y recibir información.

HTTP + JSON
REST

REST

Es un estilo arquitectónico utilizado para construir servicios web alrededor de recursos.

Arquitectura
R

Recurso

Es una entidad que queremos consultar, crear, modificar o eliminar.

Ejemplo: Producto
EP

Endpoint

Es un punto específico de acceso a una API, formado principalmente por un método HTTP y una ruta.

GET /api/productos
URI

URI

La URI identifica un recurso dentro del servicio.

/api/productos/1
02 · REST

Métodos HTTP

REST aprovecha los métodos HTTP para realizar operaciones sobre los recursos.

GET

Consultar

Obtiene información de uno o varios recursos.

GET /api/productos
POST

Crear

Permite registrar un nuevo recurso.

POST /api/productos
PUT

Actualizar

Modifica un recurso existente.

PUT /api/productos/1
DELETE

Eliminar

Elimina un recurso del servidor.

DELETE /api/productos/1

04 · WEB API

Endpoints de productos

La API contiene diferentes operaciones CRUD.

Método URI Acción Resultado
GET /api/productos Listar productos 200 OK
GET /api/productos/:id Buscar producto 200 / 404
POST /api/productos Crear producto 201 Created
PUT /api/productos/:id Actualizar producto 200 / 404
DELETE /api/productos/:id Eliminar producto 200 / 404
