API y Web API

API

¿Qué es una API?

Una API o Interfaz de Programación de Aplicaciones es un conjunto de reglas que permite que diferentes aplicaciones o sistemas puedan comunicarse entre sí.

EJEMPLO Aplicación → API → Sistema
WEB

¿Qué es una Web API?

Una Web API es una API accesible mediante tecnologías web. Normalmente utiliza el protocolo HTTP para recibir peticiones y devolver respuestas.

EJEMPLO https://servidor.com/api/productos
↔
Diferencia principal

Toda Web API es una API, pero una API no necesariamente tiene que funcionar mediante Internet o HTTP.

REST

REST es un estilo arquitectónico utilizado para diseñar servicios web.

Se basa principalmente en recursos que pueden ser consultados o modificados utilizando HTTP.

PERSONA 2

Recurso

R

¿Qué es un recurso?

Un recurso es cualquier entidad o información que una Web API permite consultar, crear, modificar o eliminar.

En REST, los recursos representan elementos reales del sistema.

👤 Usuario /api/usuarios
💻 Producto /api/productos
📦 Pedido /api/pedidos
🧾 Factura /api/facturas
RECURSO = Información del sistema que queremos manipular
04
PERSONA 2

Endpoint

EP

¿Qué es un endpoint?

Un endpoint es un punto específico de acceso dentro de una Web API.

Normalmente se identifica mediante un método HTTP junto con una ruta.

GET /api/productos Consultar productos
POST /api/productos Crear producto
PUT /api/productos/1 Actualizar producto
DELETE /api/productos/1 Eliminar producto
GET + /api/productos/1 = ENDPOINT
05
PERSONA 3

URI

URI

Uniform Resource Identifier

Identificador Uniforme de Recursos

Una URI es un identificador que permite localizar o identificar un recurso específico dentro de una Web API.

En REST, las URI deben ser claras y representar correctamente los recursos disponibles dentro del servicio.

ESTRUCTURA DE UNA URI
https://api.tienda.com /api /productos /10
↑
Dominio https://api.tienda.com

Identifica el servidor donde se encuentra publicada la Web API.

↑
Ruta /api

Indica la ruta base utilizada para acceder a los servicios de la API.

↑
Recurso /productos

Representa la entidad que queremos consultar o manipular.

↑
ID /10

Identifica específicamente un recurso dentro de la colección.

Resultado

Esta URI representa al producto con identificador 10 disponible dentro de la Web API.

En una arquitectura cliente-servidor, el cliente realiza una solicitud y el servidor procesa la petición y devuelve una respuesta.

CONCLUSIÓN

¿Cómo se relacionan estos conceptos?

Una Web API puede utilizar REST para organizar sus recursos, identificarlos mediante una URI y acceder a ellos mediante diferentes endpoints dentro de una arquitectura cliente-servidor.

Cliente → Endpoint → Recurso → Web API → Respuesta
